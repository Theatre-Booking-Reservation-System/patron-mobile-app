# Patron Mobile App Wireframes

This folder contains low-fidelity, grayscale SVG wireframes derived from the implemented Flutter routes and screens.

## Format

- Canvas: 390 × 844 px (iPhone portrait)
- Fidelity: layout, content hierarchy, navigation and primary actions
- Styling: intentionally neutral grayscale; branding and visual polish are reserved for the high-fidelity design phase
- `wireframes-overview.svg` is a contact sheet of the entire set
- Each numbered SVG is standalone and editable in Figma, Sketch, Illustrator, Inkscape or a text editor
